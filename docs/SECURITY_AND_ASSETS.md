# Repo safety and media policy

Observed GitHub repository visibility on 2026-10-10: PUBLIC. Plan accordingly.

Never commit API tokens, credentials, production secrets, account sessions, personal records, private analytics, or unreleased media. Gitignore rules are helpful but do NOT remove secrets from Git history after a mistake.

Keep full-resolution video, the original Kairo master image, audio, proprietary files and licensed clips in private asset storage. Store descriptions and public, non-sensitive references here. Do not copy material or credentials from Axiovela, the trading bot, other software repos or the cyber homelab.

This project's initial CI uses only a local dependency-free validator and no service keys. Future automated upload/publishing systems require explicit human review of permissions, cost, storage, and approval gates.

Changing visibility later cannot retract public copies already cloned.
