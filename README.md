# Kairo Knox — Beneath the System

Research-first, human-directed production and editorial workspace for an original masked AI analyst covering lesser-known, verifiable developments in artificial intelligence.

## Workflow
Discover → Read primary sources → Map claims to evidence → Investigate limitations → Draft script → Plan shots → Human review → Produce → Human approval → Publish → Learn.

## Episodes
- EP01 — AI Memory: published Oct 7, 2026 to YouTube Shorts, TikTok and Threads. Original assets are not yet imported.
- EP02 — Sleeper Agents: a revised 2026-focused script was developed; publishing has not been confirmed.
- EP03 — When AI Knows It's Being Tested: overreach and evaluation awareness; researched working script, not yet approved or published.

## Project layout
- episodes/: individual episode records, claim ledgers, scripts, and shot plans
- docs/: editorial research standards, brand guidance, safety practices and roadmap
- templates/: repeatable research and episode worksheets
- scripts/: structural validators
- .github/workflows/: automated validation on pull requests

## Human decisions are central
The creator selects topics, reads and interprets source material, verifies consequential claims, approves the Kairo character reference and final editorial output, and publishes. Tool-assisted organization must never be mistaken for independently verified facts or permission to publish.

Run npm run validate with Node.js 20+ to check metadata and evidence references. The checks DO NOT fact-check web sources.
