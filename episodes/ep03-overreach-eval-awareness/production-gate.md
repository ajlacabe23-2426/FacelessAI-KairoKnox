# EP03 — Production and publication gate

**Phase:** script + shot plan prepared. No audio/render or publishing approval is confirmed.

## Editorial
- [ ] Creator reads original A1, E1 and E2 sources
- [ ] Verify each C1–C6 statement and its limitation
- [ ] Agree on the balance between the recent Anthropic report and separate academic research
- [ ] Check news dates, model versions and any corrections
- [ ] Human approval of final narration

## Timing and voice
- [ ] Record Fraser narration of the approved script
- [ ] Measure the actual elapsed time, including intentional pauses
- [ ] If more than 75 seconds, shorten with **factual** edits; never rush through qualifications
- [ ] Confirm subtitle readability in vertical 9:16
- [ ] Check pronunciation of Anthropic and technical terminology

## Visual and assets
- [ ] Use the **original approved** black Kairo master reference
- [ ] Verify character, mask, outfit and lighting consistency across shots
- [ ] Ensure abstract interfaces are visibly illustrative, not fabricated evidence
- [ ] Source/date cards reflect the actual cited publication dates
- [ ] Music, source footage, voice, and visual licenses are appropriate

## Approval and release
- [ ] Export a draft video for creator review
- [ ] Human watch-through including sound and captions
- [ ] Creator explicitly approves final render and publication
- [ ] Publish manually to intended accounts
- [ ] Record actual platform URLs, dates and any corrections

No checkbox is automatically completed by GitHub Actions. A PR merge is not publication approval.
